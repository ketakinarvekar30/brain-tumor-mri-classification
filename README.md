# Brain Tumor MRI Classification

A deep learning pipeline that classifies brain MRI scans into four categories — **glioma**, **meningioma**, **pituitary tumor**, or **no tumor** — using a custom convolutional neural network built from scratch in PyTorch, with a live web dashboard for testing predictions.

**Test accuracy: 92.94%**

---

## Overview

This project covers the full pipeline: dataset loading and augmentation, a custom CNN architecture, training with modern techniques (AdamW, cosine annealing LR, mixed precision, early stopping), evaluation (confusion matrix, ROC/PR curves, per-class metrics), and a Flask + HTML dashboard for real-time inference.

## Dashboard

A live dashboard lets you upload an MRI scan and get an instant prediction with confidence scores, alongside the model's validation accuracy and test-set performance.

## Dataset

- **Classes:** `glioma`, `meningioma`, `notumor`, `pituitary`
- **Split:** Training folder further split 80/20 into train/validation; a separate Testing folder used only for final evaluation
- **Preprocessing:** Resize → crop to 224×224, normalized to `[-1, 1]`
- **Augmentation (training only):** random horizontal flip, small rotation (±10°), and slight affine translation/scale to reflect natural variation in scan positioning

## Model architecture

A custom 4-block CNN (`BrainCNN`), not pretrained:

- Each block: two 3×3 convolutions (with BatchNorm + ReLU) followed by max-pooling — a VGG-style design
- Channels grow 32 → 64 → 128 → 256 across the four blocks
- Global average pooling instead of a large flatten layer, to reduce overfitting risk
- Fully connected classifier head with dropout (0.5 → 0.3) before the final 4-class output

## Training setup

| Parameter | Value |
|---|---|
| Image size | 224 × 224 |
| Batch size | 64 |
| Max epochs | 50 |
| Optimizer | AdamW |
| Learning rate | 3e-4 |
| Weight decay | 1e-4 |
| Scheduler | Cosine annealing |
| Early stopping patience | 10 epochs |
| Mixed precision | Enabled |

## Results

- **Test accuracy:** 92.94%
- Full evaluation includes a confusion matrix, ROC curves, and precision-recall curves per class (generated by `evaluate.py`, saved to `outputs/plots/`)

## Setup

```bash
pip install torch torchvision torchaudio
pip install numpy pandas matplotlib scikit-learn pillow tqdm opencv-python tensorboard flask flask-cors seaborn
```

### Dataset

Place your dataset at `data/Brain_Tumor_MRI_Dataset/` with `Training/` and `Testing/` subfolders, each containing one folder per class (`glioma`, `meningioma`, `notumor`, `pituitary`). The dataset isn't included in this repo — see `config.py` for the exact expected path.

### Train the model

```bash
python train.py
```
Saves the best checkpoint to `checkpoints/best_model.pth`.

### Evaluate

```bash
python test.py          # prints accuracy/precision/recall/F1
python evaluate.py      # saves confusion matrix, ROC, PR curve plots
python plot_training.py # saves loss/accuracy/LR curve plots
python generate_metrics_json.py  # saves outputs/metrics.json for the dashboard
```

### Run the dashboard

```bash
python app.py
```
Then open `dashboard.html` in your browser.

### Predict a single image

```bash
python predict.py path/to/image.jpg
```
